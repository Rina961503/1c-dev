# Дневник разработки виджета «Отсутствия» (ночь 05.09.2026)

## Что сделано
- Виджет на главной форме: таблица отсутствий, счётчик, «+ ещё N»
- Клик по строке виджета открывает карточку существующего отсутствия
- Заголовок карточки: «Отсутствие от ДД.ММ.ГГГГ» — без номера документа
- Создана ФормаСписка с нуля, колонка «Номер» скрыта
- Защита дат: окончание не может быть раньше начала

## Грабли 
1. В управляемых формах процедура в модуле МЁРТВАЯ, пока не привязана:
   форма → F4 → «События» → «…» → выбрать процедуру.
   Вставил код руками = получил декорацию, а не обработчик.
2. Номер в заголовке карточки = АвтоЗаголовок платформы.
   Лечится: АвтоЗаголовок = Ложь + свой заголовок в ПриОткрытии.
3. Дату для заголовка читать на сервере (&НаСервере), ставить на клиенте.
4. «Изменения не применились» → проверь «Конфигурация → Обновить
   конфигурацию базы данных», а не только Ctrl+S.
5. Стандартную форму списка нельзя править, пока не создашь свою.
