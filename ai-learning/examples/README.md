# 💻 Примеры применения ИИ в 1С

Практические кейсы, где ИИ помог решить реальную задачу в разработке на 1С.

## Что здесь будет
- Примеры сгенерированного кода 1С (запросы, обработчики)
- Сравнение "до" и "после" применения ИИ
- Разбор удачных и неудачных промптов

## Формат
Каждый пример — отдельный `.md` файл с описанием задачи, промптом и результатом.
