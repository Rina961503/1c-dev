# 📝 Коллекция промптов для 1С

Здесь хранятся проверенные шаблоны промптов, которые я использую в работе с ИИ-ассистентом.

## Категории
- Генерация кода 1С (запросы, процедуры, функции)
- Рефакторинг и оптимизация
- Документирование и ТЗ
- Анализ и объяснение чужого кода

## Как использовать
Каждый промпт оформлен как отдельный `.md` файл с описанием назначения и примером результата.
